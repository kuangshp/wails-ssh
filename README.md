# 云桥

基于现有 `rust-ssh-studio` 重新实现的跨平台 SSH / SFTP 桌面客户端。独立工程，使用 **Wails v2.15.0 + Vue 3 + TypeScript + Element Plus**，Go 后端管理 SSH、SFTP 和 SQLite，xterm.js 提供真实交互式终端。

## 本地开发

依赖 Go 1.26+、Node.js 22.12+（推荐 24 LTS）、npm。macOS 需要 Xcode Command Line Tools；Windows 需要 WebView2；Linux 需要 Wails 2 对应的 GTK / WebKit 开发库。参见 [Wails 环境安装](https://v2.wails.io/docs/gettingstarted/installation/)。

```bash
cd wails-ssh
# 自动安装前端依赖，生成 Go/TS 绑定，启动原生窗口和 Vite 热更新
go run github.com/wailsapp/wails/v2/cmd/wails@v2.15.0 dev
```

不需要全局安装 Wails。也可以安装固定版本 CLI：

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@v2.15.0
wails dev
```

仅浏览前端布局：

```bash
cd frontend
npm ci
npm run dev
```

普通浏览器不具备 Go 桥接，只用于界面预览；连接与文件操作需要桌面窗口。

## 已实现

- Element Plus 连接表格、编辑表单、操作弹窗、消息提示与传输进度，统一深灰/绿色主题、表单、权限矩阵、文件菜单和传输卡片，保留 Rust 版布局：主机库的系统、名称、地址、信息、备注和操作列，以及左文件树、中间终端、右传输管理的工作区。
- 连接库：搜索、分组、备注、新增/编辑/删除，保存最近连接时间；连接后异步探测 Linux 系统、CPU、内存和磁盘信息。
- 密码、PEM / OpenSSH 私钥和加密私钥口令认证；可保留、更新或移除保存的凭据。
- 多标签 PTY 终端、ANSI / Unicode、窗口尺寸同步、复制粘贴；按主机保存最近 200 条命令，输入前缀后按 Tab 回填最近匹配项，不自动执行。无历史匹配时 Tab 交给远端 shell；方向键历史及 Ctrl+C / Ctrl+D / Ctrl+L 保持原生行为。
- 每次新 SSH 连接进入终端时显示原版服务器欢迎信息：操作系统、主机名称、内核、架构、CPU 型号/核心、内存与根盘使用、IP 地址及运行时间；独立只读通道采集，在命令提示符前输出，超时或失败不阻止终端启动，切换标签不重复输出。
- SSH 心跳、12 秒连接超时、网络断开自动重连和手动重连；正常退出不重连，重连保留终端输出，可取消。
- 连接编辑保留基本信息、连接设置等分类，可测试当前表单而不保存；不支持的跳板和代理保持明确说明。
- 文件树保留祖先及同级目录、展开/折叠与右键操作；定位终端当前目录、终端切换目录。
- 主机密钥校验：复用本机 `~/.ssh/known_hosts`，首次连接需要确认 SHA256 指纹，密钥变更拒绝连接。
- SFTP 目录浏览、路径跳转、创建文件/文件夹、重命名、权限修改、递归删除。
- 常驻传输面板，macOS 使用系统原生文件选择窗口，可一次同时选择文件和文件夹（⌘ 多选、⇧ 连选），保留 Finder 侧栏、搜索和视图；支持多次选择累加、自动去重，其他平台使用应用内混选窗口；递归上传、下载，支持取消；每个任务最多 4 路并行，工作连接持续复用，不再逐文件重新握手。
- 各终端会话的上传、下载提交状态、路径草稿、任务和冲突处理相互独立；同一会话也可同时上传和下载。冲突在所属会话的传输面板内处理，其他任务继续；仅写入同一实际目标的任务等待，防止互相覆盖。
- 上传表单跟随当前会话的终端 `cd`，无需等待文件列表刷新；手动编辑或选择的目录在当前工作目录不变时保留，下次 `cd` 再跟随。浏览文件树、延迟返回的列表不会覆盖已知的终端目录；切换会话保留各自草稿。“使用当前目录”优先使用终端工作目录。点击开始上传时目标立即固定，任务卡显示独立的“上传目录”，后续切换目录不影响已经开始的任务。上传要求绝对路径，目录准备后实际写入及重试使用已解析的固定地址。
- 传输使用独立 SFTP 连接，断线后最多重试 60 次，在同一任务中恢复临时分片，完成后原子替换；源变化拒绝续传，下载提交前校验内容。
- 上传每路最多同时发送 16 个标准 32 KiB 请求，减少逐块等待服务器响应；每 512 KiB 确认一次续传位置，失败时截断未确认窗口后重传，防止并发写入留下空洞。小文件完成后省去多余的远端删除请求。
- 上传先在本机临时目录准备整批文件副本并检查源文件与目录版本，准备完成后才修改远端；本地重新构建、移动或删除源文件不会改变已开始上传的内容。副本使用有界缓冲复制，任务结束或取消时清理，需要与本批文件大小相当的临时磁盘空间；若准备阶段源文件已经变化，会明确提示重新选择或等待生成完成，不静默跳过文件。
- 单个文件失败只停止其他文件的后续操作，等待已经发出的文件替换回执，避免人为制造其他文件的连接丢失；用户主动停止仍会立即取消整个任务。
- 进行中的上传、下载及重试任务均有明确的“停止传输”按钮；点击后显示“正在停止”，收到任务结束事件后显示“已停止”。停止只作用于该任务，已完成的文件保留。
- 同名文件可选择覆盖、跳过、全部覆盖、全部跳过或取消（“全部”仅作用于当前任务）；写入临时文件后替换目标，兼容服务器使用备份和失败回滚。
- 传输进度使用增量汇总并限频更新，显示文件完成数、跳过数和活动文件数；限制同一主机同时握手数，避免大量小文件触发连接风暴。心跳等待期间若数据仍在接收，不会误判为掉线。
- 远程压缩为 `.tar.gz`，解压 tar / tar.gz / tar.bz2 / tar.xz / zip / gzip 到新的独立目录。服务器需安装 Python 3；不覆盖现存解压目录，拒绝越界路径、链接及特殊文件。
- 导入 OpenSSH config 的具体 `Host` 条目以及旧版云桥 SQLite 连接数据。

## 数据与迁移

使用系统配置目录下的 `WailsSSH`，与 Rust 版本数据独立：

| 平台 | 默认目录 |
| --- | --- |
| macOS | `~/Library/Application Support/WailsSSH` |
| Windows | `%AppData%/WailsSSH` |
| Linux | `$XDG_CONFIG_HOME/WailsSSH` 或 `~/.config/WailsSSH` |

`servers.db` 保存连接配置和凭据；`known_hosts` 保存已确认的主机密钥。与旧版相同，密码/口令为本机 SQLite 明文，数据库文件使用当前用户权限，不调用系统钥匙串；请勿提交或公开该数据库。连接列表和普通前端配置响应不包含密码内容。

在界面选择“导入旧版数据库”，选取原来的 `RustSSHStudio/servers.db`。导入只读源文件，以名称、地址、端口、用户名去重，不修改旧项目或旧数据。迁移连接、分组字段、备注、凭据和已存系统信息；旧版独立空分组、命令历史不迁移。

OpenSSH 导入支持 `HostName`、`Port`、`User`、`IdentityFile`（含 `~/` 与引号）。通配符继承、`Include`、`Match`、`ProxyJump`、`ProxyCommand` 等高级 OpenSSH 行为尚未实现；这些配置需手动转换为可直连的连接。

## 与 Rust 版本的差异

本版终端使用完整的 xterm.js。在可识别的 Shell 提示符下，普通单行输入执行后会记录到本机，按主机隔离并保留最近 200 条。输入前缀后按 Tab 填入最近匹配的完整命令，再按 Enter 执行；Esc 隐藏该次提示后可继续使用远端 Tab 补全。工具栏或 Ctrl/Cmd+Shift+H 可打开命令历史，支持搜索、填入和单独的立即执行操作。

历史依赖远端回显和可靠提示符（例如 `root@host:~#`、`[user@host dir]$`），不适用于所有自定义提示符。密码输入、备用屏幕及无法确认的输入不记录；多行命令不提供历史补全。命令开头加空格可跳过本机自动记录。没有历史匹配时 Tab 原样交给远端，方向键仍由远端 shell 处理。

终端目录通过 OSC 7 或完整空闲提示符识别；只有目录名的提示符（例如 `[root@host app]#`）不能可靠解析绝对路径。自动重连回到账户主目录，不重放断线前的命令。跳板机、代理、RDP、Telnet、隧道保持原版未启用状态。

解压仍创建独立目录，避免覆盖现有文件；与原版解压到当前目录的冲突流程不同。文件传输拒绝符号链接，取消不会撤销该任务此前已经完成的文件。重试最多 60 次、间隔 2/4/6/8/10 秒后保持 10 秒，仅对网络错误重试；应用退出后不恢复任务。源或目标路径发生歧义时会停止，不继续覆盖；上传使用准备完成的本地副本，上传开始后的原始文件变化在下一次上传生效。同批不同来源若落到同一远程目标，会在写入前报错。为检测 SFTP 秒级修改时间无法识别的源文件变化，下载提交前会额外读取一次源内容校验 SHA-256。

若取消或失败时远端已无法访问，远端隐藏的 `.wails-ssh-*.part` 临时分片可能无法立即清理；未完成的分片不会替换原文件。无原子替换扩展的服务器采用备份后替换，遇到提交状态不明会保留可恢复路径并报错。
